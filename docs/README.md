# Documentation

This is the documentation set for DJ USB Tkit.

## Terminology

- `PDB` = `export.pdb`
- `eDB` = `exportLibrary.db`
- `master DB` = `master.db` (rekordbox's desktop library)
- `Mixxx DB` = `mixxxdb.sqlite` (Mixxx's library)
- `local DB` = app local SQLite database
